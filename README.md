# URL-Safety-Analyzer

A simple Streamlit web app that analyzes URLs and identifies potential phishing or malicious indicators. It provides a Safety Score and classifies URLs as Safe, Suspicious, or Dangerous based on common security checks.

Features
HTTPS check – warns if the URL doesn’t use HTTPS

IP address detection – flags URLs using raw IPs instead of domains

Length analysis – detects unusually long URLs

Suspicious TLDs – checks for risky domain extensions (e.g., .xyz, .tk)

Phishing keywords – scans for words like login, verify, bank

URL shortener detection – flags shortened links (e.g., bit.ly)

Subdomain count – warns if too many subdomains are present

Malware download check – detects suspicious file extensions (.exe, .zip, .rar)

Special characters – flags % or @ in URLs

Fake domain patterns – detects lookalike domains (g00gle, faceb00k)
